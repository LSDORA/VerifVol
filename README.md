# ✈️ Application de Gestion de Vols ✈️

## 📝 Description

Cette application **Java** utilise l'architecture **MVC (Model-View-Controller)** pour offrir une gestion simplifiée des billets et références de vols. Grâce à cette application, vous pouvez :

- **Stocker des billets d'avion** avec leurs informations.
- **Enregistrer des références de vols**.
- **Enregistrer des numéro de vols**.
- **Rechercher rapidement un numéro de vol** à partir de sa référence.

---

## ⚙️ Fonctionnalités

1. **Recherche intuitive :** Trouvez facilement un numéro de vol en fournissant sa référence.
2. **Stockage structuré :** Une architecture MVC garantit une séparation claire entre la logique métier, l'affichage, et les données.

---

## 🏗️ Architecture MVC

L'application est organisée selon l'architecture **MVC** pour une meilleure maintenabilité et modularité :

- **Model :** Gère la logique métier (exemple : gestion des données des billets et vols).
- **View :** Fournit l'interface utilisateur (affichage des résultats, interactions).
- **Controller :** Traite les actions de l'utilisateur et fait le lien entre le Model et la View.
